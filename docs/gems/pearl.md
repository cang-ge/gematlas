## Classification

| Property | Value |
|---|---|
| Mineral Family | Organic (calcium carbonate) |
| Formula | CaCO₃ (aragonite + conchiolin) |
| Crystal System | amorphous |

## Physical Properties

| Property | Value |
|---|---|
| Mohs Hardness | 2.5 (Soft — needs careful wear) |
| Specific Gravity | 2.7 |
| Refractive Index | 1.52-1.69 |

## Optical Properties

| Property | Value |
|---|---|
| Pleochroism | none |
| Typical Colors | White, Cream, Golden, Black (Tahitian) |
| Color Cause | Nacre interference and scattering |

## Treatments & Disclosure

| Treatment | Details |
|-----------|---------|
| Common Methods | bleaching, dyeing |
| Disclosure Required | Yes |
| Note | Natural vs cultured needs X-ray; imitations are glass/plastic beads |

## History & Lore

Pearl is the only gem produced by a living creature, symbolising purity for millennia. Persian Gulf naturals and Kokichi Mikimoto's cultured pearls built the modern industry.
