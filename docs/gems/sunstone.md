> Feldspar (Oligoclase / Labradorite)

中文: [太阳石](/zh/gems/sunstone)

## Classification

| Property | Value |
|---|---|
| Mineral Family | Feldspar (Oligoclase / Labradorite) |
| Formula | (Na,Ca)(Si,Al)₄O₈ + Cu/Fe platelets |
| Crystal System | triclinic |

## Physical Properties

| Property | Value |
|---|---|
| Mohs Hardness | 6.25 |
| Specific Gravity | 2.64 |
| Refractive Index | 1.537-1.547 |

## Optical Properties

| Property | Value |
|---|---|
| Pleochroism | none |
| Typical Colors | Red-orange with golden shimmer, Peach, Yellow-green |
| Color Cause | Copper/hematite platelets produce aventurescence (see Optical Phenomena — Aventurescence) |

## Treatments & Disclosure

| Treatment | Details |
|-----------|---------|
| Common Methods | None / Typically untreated |
| Disclosure Required | No |
| Note | Oregon sunstone is famous for natural copper platelets that need no enhancement |
