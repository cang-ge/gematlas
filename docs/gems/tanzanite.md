## Classification

| Property | Value |
|---|---|
| Mineral Family | Zoisite |
| Formula | Ca₂Al₃(SiO₄)₃(OH) |
| Crystal System | orthorhombic |

## Physical Properties

| Property | Value |
|---|---|
| Mohs Hardness | 6.5 (Relatively brittle) |
| Specific Gravity | 3.35 |
| Refractive Index | 1.691-1.700 |

## Optical Properties

| Property | Value |
|---|---|
| Pleochroism | strong |
| Typical Colors | Blue-Violet, Violet-Blue |
| Color Cause | Vanadium (V³⁺) trace ions |

## Treatments & Disclosure

| Treatment | Details |
|-----------|---------|
| Common Methods | heat-treatment |
| Disclosure Required | Yes |
| Note | Almost all tanzanite is heat-treated to enhance blue-violet |

## Origin

| Region |
|---|
| Merelani Hills, Tanzania |

## History & Lore

Found near Arusha in 1967 and promoted by Tiffany. With a single source worldwide, it is exceptionally rare.
