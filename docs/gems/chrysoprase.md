> Quartz (microcrystalline chalcedony)

<!-- language switcher hint -->
中文: [绿玉髓](/zh/gems/chrysoprase)

---

## Classification

| Property | Value |
|---|---|
| Mineral Family | Quartz (microcrystalline chalcedony) |
| Formula | SiO₂ + Ni |
| Crystal System | trigonal |

## Physical Properties

| Property | Value |
|---|---|
| Mohs Hardness | 7 |
| Specific Gravity | 2.6 |
| Refractive Index | 1.530-1.543 |

## Optical Properties

| Property | Value |
|---|---|
| Pleochroism | none |
| Typical Colors | Apple green, Bright green, Mint green |
| Color Cause | Ni²⁺ inclusions or Ni substituting for Si produce green |

## Treatments & Disclosure

| Treatment | Details |
|-----------|---------|
| Common Methods | wax-impregnation |
| Disclosure Required | Yes |
| Note | Color may fade under prolonged sunlight; distinct from dyed green agate |
