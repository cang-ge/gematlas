## Classification

| Property | Value |
|---|---|
| Mineral Family | Hydrous copper aluminium phosphate |
| Formula | CuAl₆(PO₄)₄(OH)₈·4H₂O |
| Crystal System | triclinic |

## Physical Properties

| Property | Value |
|---|---|
| Mohs Hardness | 6 |
| Specific Gravity | 2.7 |
| Refractive Index | 1.61-1.65 |

## Optical Properties

| Property | Value |
|---|---|
| Pleochroism | weak |
| Typical Colors | Sky blue, Blue-green, Green |
| Color Cause | Cu blue, Fe green |

| Treatment | Details |

Turquoise is among the oldest gems — sacred to Egyptian pharaohs, Native Americans, and Tibetan culture.
