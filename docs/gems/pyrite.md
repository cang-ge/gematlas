## Classification

| Property | Value |
|---|---|
| Mineral Family | Sulfide |
| Formula | FeS₂ |
| Crystal System | cubic |

## Physical Properties

| Property | Value |
|---|---|
| Mohs Hardness | 6.5 |
| Specific Gravity | 5.01 |

| Property | Value |
|---|---|
