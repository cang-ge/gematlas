# Mineral Groups

Natural gems fall into distinct families by chemistry and crystal structure. The nine below are the most important in gemology:

## Nine Major Groups

| Group | Formula Class |
|---|---|
| [Native Elements](native-elements) | Single-element composition |
| [Oxides](oxides) | M₂O₃ / MO₂ / MO |
| [Silicates — Framework (Tectosilicates)](silicates-framework) | M(Al,Si)₄O₈ |
| [Silicates — Chain / Band (Inosilicates)](silicates-chain) | M·SiO₃ / M₇Si₈O₂₂(OH)₂ |
| [Silicates — Isolated Tetrahedra / Rings](silicates-isolated) | M₃Al₂(SiO₄)₃ / M₃(SiO₄) + Si₃O₉ |
| [Phosphates](phosphates) | PO₄³⁻ group + metal cations |
| [Carbonates](carbonates) | CO₃²⁻ + divalent metal cations |
| [Sulfides](sulfides) | M_xS_y (with S²⁻) |
| [Halides](halides) | MX (X = F, Cl, Br, I) |
