# GIA 4C 钻石分级

## 概述

GIA 于 1953 年确立的全球通用钻石分级标准。四要素——克拉、颜色、
净度、切工——相互独立又联合决定钻石价格。


## 核心要点

- 克拉 (ct)：1 ct = 0.2 g；1 point = 0.01 ct。重量越大稀有度指数级上升。
- 颜色：D–Z 色级，仅指黄/棕色调，从完全无色到浅黄/浅棕。
- 净度：FL–I3 十级，10× 放大镜下内含物数量与位置决定。
- 切工：Excellent / Very Good / Good / Fair / Poor 五级，比例决定火彩。
