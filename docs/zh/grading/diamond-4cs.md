# GIA 4C 钻石分级

## 概述

GIA 于 1953 年确立并广泛采用的钻石分级框架。四要素——克拉、颜色、
净度、切工——用于组织钻石质量描述，不等同于价格公式。

## 核心要点

- 克拉 (ct)：1 ct = 0.2 g；1 point = 0.01 ct。重量是计量字段，不是统一的稀有度或价格公式。
- 颜色：D–Z 色级，仅指黄/棕色调，从完全无色到浅黄/浅棕。
- 净度：FL–I3 共 11 个等级，10× 放大镜下由内含物与表面特征决定。
- 切工：Excellent / Very Good / Good / Fair / Poor 五级；比例、对称性、抛光与光学表现需要结合理解。
