# 彩色宝石分级（hue / tone / saturation）

## 概述

彩色宝石不像钻石有标准化 4C，而是用三维度描述颜色——hue（色相）、tone
（色调明暗）、saturation（饱和度）。许多实验室会使用这组描述维度，
但具体报告术语与阈值可能不同。

## 核心要点

- hue：色相在色环上的位置；具体优选色相会因宝石品种和报告体系而异。
- tone：色调明暗；有些体系会使用分档描述，但档位和优选区间不应被视为所有实验室的统一规则。
- saturation：色彩饱和度；高饱和度并非所有品种或市场的统一最佳条件。
- 颜色通常是重要质量因素，但切工、净度、耐久性、处理、尺寸和供需也会影响市场评价。

## 示例

| 宝石 | 等级 | 备注 |
|---|---|---|
| 红宝石 | vivid red, medium tone | “鸽血红”需结合品种、实验室体系和语境 |
| 祖母绿 | vivid green, slightly bluish | Muzo / Chivor 可能涉及产地或商业语境，不是统一等级 |
| 蓝宝石 | vivid blue, medium-dark | royal / cornflower 需核对报告体系和使用范围 |
