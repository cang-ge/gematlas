# 分级

分级是把宝石的外观、重量与报告特征组织成可比较描述的行业惯例；
真实性由鉴定与处理披露支持，而不是由分级单独证明。
本模块讲解 GIA 4C 钻石分级框架（Carat / Color / Clarity / Cut），
以及彩色宝石独立的 hue-tone-saturation 模型，
并说明净度特征、处理披露与产地意见之间的边界。

## 分级主题

| 主题 | 概述 |
|---|---|
| [GIA 4C 钻石分级](diamond-4cs) | GIA 于 1953 年确立并广泛采用的钻石分级框架。四要素——克拉、颜色、 净度、切工——用于组织钻石质量描述，不等同于价格公式。 |
| [彩色宝石分级（hue / tone / saturation）](colored-stones) | 彩色宝石不像钻石有标准化 4C，而是用三维度描述颜色——hue（色相）、tone （色调明暗）、saturation（饱和度）。许多实验室会使用这组描述维度， 但具体报告术语与阈值可能不同。 |
| [净度瑕疵类型 (inclusion / blemish)](clarity-types) | 宝石内含物 (inclusion) 与表面瑕疵 (blemish) 的种类、位置、数量、 可见性共同参与净度描述。同种特征在不同宝石中的意义不同，需要结合品种、 位置、耐久性和观察条件理解。 |
| [产地 / 处理披露](origin-disclosure) | 处理状态和产地意见属于披露与实验室报告语境，适用要求取决于司法辖区、 规则、报告和交易场景；它们不是同一套分级指标。 |
