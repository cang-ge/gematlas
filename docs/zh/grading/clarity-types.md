# 净度瑕疵类型 (inclusion / blemish)

## 概述

宝石内含物 (inclusion) 与表面瑕疵 (blemish) 的种类、位置、数量、
可见性共同决定净度等级。同种瑕疵在不同宝石中影响不同——
祖母绿中的"花园"是常态，钻石中却致命。


## 核心要点

- feather：羽状裂隙，最影响耐久性。
- cloud：云状包体，密集时影响透明度。
- crystal / mineral：结晶包裹体（金红石、锆石、方解石）。
- needle：金红石针状——蓝宝石"丝绒感"的关键。
- blemish / chip / scratch：表面瑕疵。
- 位置比类型更关键——亭部深处 vs 台面正中可见，影响差几倍。

## 示例

| 宝石 | 等级 | 备注 |
|---|---|---|
| emerald | jardin (3-phase) | 公认美感一部分 |
| ruby | silk (rutile needles) | 星光效应来源 |
