# 净度瑕疵类型 (inclusion / blemish)

## 概述

宝石内含物 (inclusion) 与表面瑕疵 (blemish) 的种类、位置、数量、
可见性共同参与净度描述。同种特征在不同宝石中的意义不同，需要结合品种、
位置、耐久性和观察条件理解。

## 核心要点

- feather：羽状裂隙；耐久性影响取决于位置、是否达到表面、方向、大小和宝石品种。
- cloud：云状包体，密集时影响透明度。
- crystal / mineral：结晶包裹体（金红石、锆石、方解石）。
- needle：金红石针状——蓝宝石"丝绒感"的关键。
- blemish / chip / scratch：表面瑕疵。
- 位置会改变可见性、净度判断和耐久性风险，不能用单一倍数概括。

## 示例

| 宝石 | 等级 | 备注 |
|---|---|---|
| 祖母绿 | jardin (3-phase) | 品种语境中的内含物描述，仍需结合透明度和耐久性 |
| 红宝石 | silk (rutile needles) | 可能与星光效应相关，需结合方向、密度和切磨 |
