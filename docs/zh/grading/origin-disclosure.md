# 产地 / 处理披露

## 概述

处理状态和产地意见属于披露与实验室报告语境，适用要求取决于司法辖区、
规则、报告和交易场景；它们不是同一套分级指标。

## 核心要点

- “No Indications of Treatment”表示未观察到处理迹象，不等于绝对证明从未处理；价格也不能仅凭这一项确定。
- 一般处理 (常规)：如红/蓝宝石热处理，是否需要披露取决于适用规则、报告和交易语境；不能作全球统一法律结论。
- 优化处理 (enhancement)：如祖母绿浸油 / 染色 / 填充，需同时说明稳定性、护理、报告用语和适用披露规则。
- 产地意见 (origin opinion)：结合包裹体组合与微量元素等证据，由实验室出具意见，可能无法判定，也不是宝石分级。

## 示例

| 宝石 | 等级 | 备注 |
|---|---|---|
| 红宝石 | heated (H) | 处理披露示例；不单独推出价格上限 |
| 祖母绿 | minor oil (Cedarwood) | 需结合稳定性、护理、报告用语和适用规则 |
| 蓝宝石 | unheated, Kashmir | 未观察到处理迹象与产地意见是两个独立维度 |
