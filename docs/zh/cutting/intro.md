# 切割

切割是把原石转化为宝石的工艺与科学，可以从两个层面理解：一是成品形态，
如刻面、蛋面与雕刻；二是刻面内部的轮廓与切面风格，如圆明亮式、祖母绿式、
公主方、梨形和马眼形。路线选择还要综合透明度、包裹体、耐久性、光学效应与原石形状。


## 切割主题

| 主题 | 概述 |
|---|---|
| [原石规划与定向](rough-planning) | 切工不是从“选择一个漂亮轮廓”开始，而是先读懂原石：观察体色分布、裂隙、 包裹体、透明度、晶体方向与潜在光学效应，再在重量保留、视觉效果和耐久性之间 做出取舍。规划图应记录台面方向、预计轮廓、主要风险和允许的损耗范围。 |
| [圆明亮式切工](brilliant-cut) | 圆明亮式是经典的刻面风格之一，最常见于钻石。1919 年 Marcel Tolkowsky 对相关比例体系的研究使其成为讨论台面、冠部、腰棱和亭部关系的经典参考。 对于适合该比例体系的透明材料，合理的部位关系有助于提升亮度、闪烁与火彩表现。 |
| [花式切工](fancy-cuts) | 非圆明亮式的异形、阶梯式与改良明亮式切工通常归入花式切工——公主方、祖母绿切、梨形、 椭圆形、马眼形、心形、祖母绿阶梯切等。每种依原石形状、内含物 位置与审美偏好而选。 |
| [蛋面与雕刻](cabochon-and-carving) | 当透明度、包裹体、耐久性或特殊光学效应更适合弧面时，宝石常采用蛋面 （凸圆打磨）或雕刻；这不是对所有材料的绝对限制。蛋面可突出星光、 猫眼、月光等现象，玉石与玛瑙也常见雕刻路线。 |
