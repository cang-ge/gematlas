# 切割

切割是把原石转化为宝石的工艺与科学。本模块讲解三类主切割路线——
刻面切割（faceting，面向透明宝石）、蛋面/雕刻（cabochon & carving，
面向不透明或具光学效应宝石），以及花式切工的历史与参数。


## 切割主题

| 主题 | 概述 |
|---|---|
| [圆明亮式切工](brilliant-cut) | 现代最经典的钻石切工，标准 57–58 刻面，诞生于 1919 年 |
| [花式切工](fancy-cuts) | 除圆明亮式外的所有切工统称花式切工——公主方、祖母绿切、梨形、 |
| [蛋面与雕刻](cabochon-and-carving) | 不透明或具特殊光学效应的宝石不适合刻面——改用蛋面（凸圆打磨）或 |
