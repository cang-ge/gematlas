# 花式切工

## 概述

除圆明亮式外的所有切工统称花式切工——公主方、祖母绿切、梨形、
椭圆形、马眼形、心形、祖母绿阶梯切等。每种依原石形状、内含物
位置与审美偏好而选。


## 核心要点

- 公主方 (princess)：方形，保留圆明亮火彩，现代婚戒主流。
- 祖母绿切 (emerald)：阶梯式刻面，突出净度——适合高净度大石。
- 梨形/马眼/心形：异形轮廓，需冠亭比例对称避免"蝴蝶结效应"。
- 花式切工按尺寸定价时单克拉价常低于圆明亮（切工损耗与需求差异）。
