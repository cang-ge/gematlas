# 花式切工

## 概述

非圆明亮式的异形、阶梯式与改良明亮式切工通常归入花式切工——公主方、祖母绿切、梨形、
椭圆形、马眼形、心形、祖母绿阶梯切等。每种依原石形状、内含物
位置与审美偏好而选。

## 案例流程

> 教学案例（演示）：异形轮廓的价值判断不能由轮廓名称单独推出。

### 1. 明确目标

先写清楚目标是最大化原石利用、突出轮廓、降低尖角风险，还是改善视觉表现；目标不同，
对长宽比、尖角处理和损耗的容忍度就不同。

### 2. 对照轮廓与刻面

以同一原石分别比较梨形、马眼形或祖母绿阶梯式等候选，记录长宽比、对称性、尖角、
阶梯/明亮刻面组织和可能的蝴蝶结暗区。轮廓只是入口，不能代替比例与抛光检查。

### 3. 进行视觉复核

统一旋转样品和光源，观察明暗是否均匀、尖端是否过薄、左右是否失衡；把不同角度看到的
结果分别记录，避免用一个角度代表全部表现。

### 4. 停止条件

如果蝴蝶结、尖角耐久性或对称性无法在当前资料下判断，就保留多个方案，不把“更好看”
写成确定结论，也不直接推导价格。


## 核心要点

- 公主方 (princess)：方形，保留圆明亮火彩，现代婚戒主流。
- 祖母绿切 (emerald)：阶梯式刻面，突出净度——适合高净度大石。
- 梨形/马眼/心形：异形轮廓，需冠亭比例对称避免"蝴蝶结效应"。
- 切工质量、轮廓、比例、对称性和抛光会共同影响视觉表现与市场评价，具体价值还会随品种与市场变化。
