# 原石规划与定向

## 概述

切工不是从“选择一个漂亮轮廓”开始，而是先读懂原石：观察体色分布、裂隙、
包裹体、透明度、晶体方向与潜在光学效应，再在重量保留、视觉效果和耐久性之间
做出取舍。规划图应记录台面方向、预计轮廓、主要风险和允许的损耗范围。

## 案例流程

> 教学案例（演示）：以下是一条记录方法，不是真实样品的加工指令。

### 1. 输入观察

先记录重量、外形、透明度、体色分布、可见裂隙、包裹体、晶体方向和可能的光学效应；
对不确定的区域标记“待复核”，不直接把照片或肉眼印象写成结论。

### 2. 形成两个候选方案

至少保留一个“保重优先”和一个“表现/耐久优先”的方案，分别写明预计轮廓、台面方向、
主要损耗、风险区域与放弃条件。这样能解释取舍，而不是只展示最终形状。

### 3. 复核与记录

用同一光源、同一观察方向和同一记录模板比较候选方案；重新检查尖角、薄腰棱、裂隙延伸
与应力集中位置。若信息不足以判断，应保留候选，不强行进入加工。

### 4. 停止条件

无法确认裂隙风险、光学效应方向或设备安全范围时，停止下料并交由受训切割师复核。


## 核心要点

- 先观察再下料：清洁、测量并在不同光线与方向下检查原石，标记裂隙、包体和色带。
- 定向优先：有色带、猫眼、星光或变彩时，台面方向会直接影响颜色与现象的呈现。
- 取舍要透明：保留重量不等于保留价值；过度追重可能牺牲亮度、对称性或耐久性。
- 规划需留安全边界：尖角、薄腰棱、深裂隙和应力集中区域应在设计阶段避开或加固。
- 最终方案应能解释“为什么这样切”，而不只是记录成品的形状。

## 示例

| 宝石 | 切工 | 备注 |
|---|---|---|
| 欧泊 | 台面朝向最强变彩区域 | 优先呈现变彩区域 |
| 星光蓝宝石 | 让弧顶对准交叉的丝状包体 | 使星线集中于弧顶 |
