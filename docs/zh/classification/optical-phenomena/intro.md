# 光学现象

除了基础颜色，天然宝石可通过内部结构展示多种独特的光学效应。以下七种是最具代表性、也最容易在鉴定中观察到的现象：

## 先学会观察

| 现象 | 建议观察方式 | 优先寻找的结构线索 |
|---|---|---|
| 星光效应 | 单点光源直射并缓慢转动弧面宝石 | 定向针状或管状包裹体 |
| 猫眼效应 | 移动光源或转动弧面宝石，追踪亮带 | 平行纤维、管状包裹体或通道 |
| 变色效应 | 分别在日光与暖色光源下比较 | 不同光源光谱与选择性吸收 |
| 变彩（游彩） | 缓慢倾斜，观察色斑移动与分布 | 有序二氧化硅微球结构 |
| 月光效应 | 转动弧面宝石，观察漂浮光晕 | 长石内部交替层状结构 |
| 拉长晕彩 | 改变角度，观察金属感色彩闪烁 | 长石成分层状结构 |
| 砂金效应 | 倾斜宝石，让片状包裹体依次反光 | 定向金属片状包裹体 |

## 七种主要现象

| 现象 | 一句话概述 |
|---|---|
| [星光效应](asterism) | 平行针状包裹体反射光线形成星芒 |
| [猫眼效应](chatoyancy) | 平行纤维或管状包裹体形成一道亮带 |
| [变色效应](color-change) | 不同光源下呈现明显不同颜色 |
| [变彩（游彩）](play-of-color) | 角度变化时出现跳动的光谱色斑 |
| [月光效应](adularescence) | 内部层状结构产生柔和漂浮的蓝色光晕 |
| [拉长晕彩](labradorescence) | 内部层状结构产生强烈金属光泽的彩色闪烁 |
| [砂金效应](aventurescence) | 金属片状包裹体在宝石内部闪烁 |

观察到一个现象，只能说明宝石呈现了某种光学表现，不能单独作为最终鉴定结论。光源、切磨形状、观察角度和内部包裹体都会影响结果。
