# 四方晶系

## 概述

四方晶系具有两条等长的水平轴与一条不等长的纵向轴。晶体光学上
为一轴晶，光轴平行于 c 轴；多数宝石为正光性，少数为负光性。
c 轴方向为非寻常光折射率方向。


## 晶体学参数

| 属性 | 值 |
|---|---|
| 晶轴 | a = b ≠ c |
| 夹角 | α = β = γ = 90° |
| 对称性等级 | medium-high |
| 光学分类 | uniaxial |
| 光性 | + |
| 双折射率范围 | 0.040–0.300 |
| 解理 | parallel to base (001) |
| 常见晶形 | 四方柱、四方双锥、板状 |

## 主要宝石

| 宝石 | 折射率 | 比重 |
|---|---|---|
| Zircon | 1.810–2.024 | 4.60–4.80 |
| Rutile | 2.616–2.903 | 4.20–5.20 |
| Idocrase (Vesuvianite) | 1.700–1.732 | 3.32–3.42 |
| Scapolite | 1.540–1.579 | 2.57–2.78 |
