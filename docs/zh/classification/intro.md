## 01 · 它是什么：材料与成因

许多天然宝石与矿物有关，但宝石材料并不只有矿物。GemAtlas 将材料先按来源与性质区分，再通过晶体结构、光学现象和颜色成因继续细分。

| 材料类别 | 判断重点 | 代表材料 |
|---|---|---|
| 天然矿物 | 天然形成，具有相对明确的化学组成与晶体结构 | 刚玉、绿柱石、石英、金刚石 |
| 类矿物 / 非晶质材料 | 有宝石属性，但不具备完整的长程晶体结构 | 欧泊、黑曜石 |
| 有机材料 | 由生物活动或生物成因形成 | 珍珠、琥珀、珊瑚 |
| 实验室合成材料 | 在实验室制造，化学与结构可接近天然对应物 | 合成红宝石、合成祖母绿、CVD 钻石 |
| 仿制品 | 用另一种材料模拟目标宝石的外观 | 立方氧化锆、玻璃、莫桑石 |

### 矿物族中的代表宝石

| 矿物族 | 代表宝石 |
|---|---|
| 刚玉 | 红宝石、蓝宝石 |
| 绿柱石 | 祖母绿、海蓝宝、摩根石 |
| 石英 | 紫晶、黄水晶、水晶 |
| 石榴石 | 沙弗莱、翠榴石、铁铝榴石 |
| 电气石 | 帕拉伊巴、西瓜碧玺 |
| 尖晶石 | 红色、蓝色尖晶石 |
| 金刚石 | 无色钻石、彩钻 |
| 长石 | 月光石、拉长石、天河石 |
| 黝帘石 | 坦桑石 |
| 蛋白石 | 贵欧泊、火欧泊 |

> “贵重宝石”和“半贵重宝石”是传统商业语境中的称呼，不是现代宝石学的严格科学分类。判断价值时，更应关注稀有度、美观度、耐久性、处理情况与市场需求。

## 02 · 它如何排列：晶系与结构

晶体结构描述原子或离子在空间中的有序排列。宝石学中常用七大晶系来描述晶体对称性；欧泊、黑曜石和琥珀等非晶质或类矿物材料，则需要单独理解。

| 晶系 | 代表宝石 | 观察提示 |
|---|---|---|
| 等轴晶系 | 钻石、尖晶石、石榴石 | 三个轴长度相等，方向关系对称 |
| 四方晶系 | 锆石、金红石 | 两个轴相等，第三轴不同 |
| 斜方晶系 | 坦桑石、亚历山大石、托帕石 | 三个轴长度不同，彼此垂直 |
| 六方晶系 | 绿柱石、磷灰石 | 六重对称轴是重要特征 |
| 三方晶系 | 红宝石、蓝宝石、石英、电气石 | 以三重对称性识别 |
| 单斜晶系 | 正长石、锂辉石 | 轴间夹角并非全部为直角 |
| 三斜晶系 | 蓝晶石、绿松石 | 对称性最低，三个轴均不等且不垂直 |
| 非晶质 / 类矿物 | 欧泊、黑曜石、琥珀 | 不具备完整的长程晶体有序结构 |

*从[等轴晶系](crystal-systems/cubic)开始，逐页观察晶体结构与宝石性质的关系。*

## 03 · 它如何呈现光：光学现象

光学现象是观察宝石的重要入口，但现象名称、成因和商业名称不应混为一谈。本项目将“看见的效果”与“产生效果的结构或包裹体”分开记录。

| 现象 | 主要表现 | 代表材料 |
|---|---|---|
| 星光效应 | 光线形成交叉星芒 | 星光红宝石、星光蓝宝石 |
| 猫眼效应 | 出现一条可移动的亮带 | 猫眼金绿宝石、虎睛石 |
| 变色效应 | 在不同光源下呈现不同颜色 | 亚历山大石、变色蓝宝石 |
| 变彩 / 游彩 | 宝石表面或内部出现随角度变化的彩色闪光 | 欧泊 |
| 晕彩 | 薄层或层状结构产生彩虹般的干涉色 | 拉长石等 |
| 月光效应 | 出现柔和的蓝白色漂浮光晕 | 月光石 |
| 砂金效应 | 内部片状包裹体产生闪烁 | 砂金石、日光石 |

*进入[光学现象](optical-phenomena/intro)，查看各类效果的成因、观察方式与鉴定提示。*

## 04 · 它为何有色：颜色成因

颜色不是孤立的外观标签，而是光与物质相互作用后的结果。常见致色机制包括：

| 机制 | 核心问题 | 代表方向 |
|---|---|---|
| 过渡金属离子 | 晶格中的离子选择性吸收哪些可见光 | 铬、铁、锰、钴、铜等 |
| 色心 | 晶格缺陷如何改变光的吸收 | 空位、间隙与辐照相关缺陷 |
| 电荷转移 | 电子在相邻离子或能级之间如何跃迁 | 金属—金属、氧—金属等 |

颜色分类适合帮助观察和检索，但不能替代鉴定。真正的颜色描述还要结合色相、明度、饱和度、光源和观察方向。

*详见[颜色成因](color-causes/intro)，从物理化学机制理解宝石为什么会呈现不同颜色。*

## 05 · 从分类坐标进入宝石名录

同一颗宝石可以同时拥有多个坐标：例如欧泊属于非晶质材料，也可能呈现变彩 / 游彩；蓝宝石属于刚玉族，并具有三方晶系。分类不是把宝石放进唯一的盒子，而是建立多维检索关系。
