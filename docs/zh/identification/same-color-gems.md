# 同色宝石判别

## 概述

同一种颜色可能对应多种宝石——红色可能是红宝石、尖晶石、石榴石或玻璃。
结合 RI / SG / 多色性 / 包裹体，可把同色宝石逐一排除。以下流程图
覆盖红色、蓝色、绿色三大最易混淆家族。


## 鉴定步骤

**1. 用折射仪测量折射率（RI）**

| RI 读数 | 可能家族 | 下一步 |
|---|---|---|
| 1.76 | 刚玉（红宝石/蓝宝石）| 第 2 步 |
| 1.71–1.72 | 尖晶石候选 | 需结合 SG、包裹体与光谱复核 |
| 1.74–1.89 | 石榴石候选 | 需结合 SG、包裹体与光谱复核 |
| 1.5–1.7，玻璃感 | 疑似玻璃 | 第 3 步 |

**2. 对刚玉检测紫外荧光（LW 紫外灯）**

| 荧光 | 结论 |
|---|---|
| 强红 | 支持红宝石候选，仍需复核 |
| 弱或无 | 不能单独排除红宝石，需进一步检测 |

**3. 对疑似玻璃观察气泡 / 旋涡纹**

| 观察 | 结论 |
|---|---|
| 有气泡或流动纹 | 支持玻璃仿品候选 |
| 无 | 不能排除仿品，复查读数并补充检测 |


## 核心要点

- 红：红宝石 RI 1.76 + 强红荧光；尖晶石 1.71–1.72 无荧光；石榴石 1.74–1.89。
- 蓝：蓝宝石约 1.76，可能见二色性；坦桑石 1.69–1.70 强三色性；堇青石 1.54 三色性极强。
- 绿：祖母绿 1.57–1.58（浸油裂隙）；翠榴石 1.89 高色散；橄榄石 1.65–1.69（双影）。
- 荧光只能作为筛分线索：天然红宝石常见 LW 红色反应，但强弱受产地、处理与样品影响；合成品也可能出现相近反应。
- 任何单一观察都不能替代实验室鉴定；紫外灯、划痕和液体测试须按器材安全规范操作。

|---|---|---|

| emerald | RI 1.57 + oil fissures | — |
