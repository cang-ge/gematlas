# 鉴定

鉴定是一门测量物理与光学性质来区分天然宝石、合成品与仿品的学科。
本模块介绍三大类测试——物理性质测试（RI / SG / 硬度 / 解理）、
光学测试（双折射 / 多色性 / 紫外荧光）、以及合成品与仿品的鉴别要点。
