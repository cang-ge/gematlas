# 鉴定

鉴定是通过可记录、可复核的物理与光学证据，逐步缩小材料候选范围的工作。
本模块适合学习观察、基础筛分和证据记录，不把外观或单项读数包装成确定答案。
推荐路径是：先记录样品与任务边界，再做低风险观察，之后按风险递进进行物理/光学测试，
最后区分“支持候选”“与候选一致”和“无法排除”，必要时转交专业实验室。

**你可以用本模块做什么：** 学会描述样品状态、记录测试条件、理解 RI / SG / 光学现象
在证据链中的作用，并形成一份教育性的筛分记录。

**你不能仅凭本模块做什么：** 不能仅凭照片、外观、单个仪器读数或 Assist 判断具体样品的
天然/合成身份、处理状态、产地、分级或价值；涉及高价值交易、保险、产地意见或天然/合成
披露时，应保留原始记录并交由具备资质的实验室完成检测。


## 鉴定主题

| 主题 | 概述 |
|---|---|
| [鉴定工作流与记录](identification-workflow) | 专业鉴定不是寻找一个“神奇读数”，而是建立可复核的证据链。先记录样品状态， 再从低风险观察开始，逐步组合物理、光学和包裹体线索；最后明确结论的置信边界、 处理披露与是否需要实验室报告。 |
| [物理性质测试](physical-tests) | 折射率 (RI)、比重 (SG)、硬度、解理是最基础的鉴定手段——它们由 矿物化学成分与晶体结构影响；同一品种通常落在可比的特征范围， 但测量条件、方向、处理和样品状态都会影响读数。 |
| [光学测试](optical-tests) | 双折射（偏光镜）、多色性（二色镜）、紫外荧光（紫外灯）提供宝石的 光学与材料线索，可用于快速筛分品种并提示进一步检测方向。 |
| [合成品与仿品鉴别](synthetic-and-imitation) | 判断材料时至少要分别记录四个维度：天然或人工生长、是否经过处理、是否为不同材料仿品， 以及是否存在双层石/三层石等复合结构。合成宝石、仿品、处理品和复合材料的证据路径不同， 典型线索都只能支持候选，不能替代实验室披露。 |
| [同色宝石判别](same-color-gems) | 同一种颜色可能对应多种宝石——红色可能是红宝石、尖晶石、石榴石或玻璃。 结合 RI / SG / 多色性 / 包裹体，可以逐步缩小候选范围，但重叠与无法排除是正常结果。 当前提供红、蓝、绿三个最小教育性分流案例；它们用于训练“候选—证据—下一步”，不是覆盖所有材料的完整决策树。 |
