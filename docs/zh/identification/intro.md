# 鉴定

鉴定是一门测量物理与光学性质来区分天然宝石、合成品与仿品的学科。
本模块介绍三类基础测试——物理性质测试（RI / SG / 硬度 / 解理）、
光学测试（双折射 / 多色性 / 紫外荧光）、以及合成品与仿品的鉴别；
另以同色宝石判别作为综合应用练习。


## 鉴定主题

| 主题 | 概述 |
|---|---|
| [鉴定工作流与记录](identification-workflow) | 专业鉴定不是寻找一个“神奇读数”，而是建立可复核的证据链。先记录样品状态， 再从低风险观察开始，逐步组合物理、光学和包裹体线索；最后明确结论的置信边界、 处理披露与是否需要实验室报告。 |
| [物理性质测试](physical-tests) | 折射率 (RI)、比重 (SG)、硬度、解理是最基础的鉴定手段——它们由 矿物化学成分与晶体结构影响；同一品种通常落在可比的特征范围， 但测量条件、方向、处理和样品状态都会影响读数。 |
| [光学测试](optical-tests) | 双折射（偏光镜）、多色性（二色镜）、紫外荧光（紫外灯）提供宝石的 光学与材料线索，可用于快速筛分品种并提示进一步检测方向。 |
| [合成品与仿品鉴别](synthetic-and-imitation) | 合成宝石（同化学成分，如焰熔法红宝石、水热法祖母绿、CVD 钻石）与 仿品（不同成分，如玻璃、立方氧化锆、仿祖母绿双层石）需要不同的 鉴别路径。 |
| [同色宝石判别](same-color-gems) | 同一种颜色可能对应多种宝石——红色可能是红宝石、尖晶石、石榴石或玻璃。 结合 RI / SG / 多色性 / 包裹体，可把同色宝石逐一排除。以下流程图 覆盖红色、蓝色、绿色三大最易混淆家族。 |
