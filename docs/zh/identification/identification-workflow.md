# 鉴定工作流与记录

## 概述

专业鉴定不是寻找一个“神奇读数”，而是建立可复核的证据链。先记录样品状态，
再从低风险观察开始，逐步组合物理、光学和包裹体线索；最后明确结论的置信边界、
处理披露与是否需要实验室报告。

## 鉴定步骤

**1. 先记录样品与任务边界**

记录尺寸、重量、镶嵌状态、已知来源、可见损伤和委托目的。镶嵌石、涂油石或无法接触
的样品，应在记录中注明哪些测试无法可靠完成。

**2. 从无损观察开始**

在白光、点光源和适当放大下观察体色、透明度、光泽、切工、包裹体与光学现象；先写下
观察事实，再写候选判断，避免把名称当成观察结果。

**3. 按风险递进测试**

优先考虑折射率、偏光镜、二色镜、紫外荧光和光谱等非破坏性线索；比重测试要评估样品
是否适合浸液，划痕测试只在必要且获准时考虑。

**4. 交叉验证与分级结论**

将读数与候选品种的特征范围、处理可能性和样品限制逐项比对。结论应区分“支持候选”、
“与候选一致”和“无法排除”，不要把单项测试写成最终鉴定。

**5. 需要时转交实验室**

涉及天然/合成判断、产地意见、重大交易或保险用途时，应保留原始记录并交由具备资质的
实验室完成更高阶检测。

**可复制鉴定记录卡（最小版）**

| 区块 | 记录内容 |
|---|---|
| 样品与任务 | 样品编号、日期、操作者、送检目的、裸石/镶嵌/复合材料 |
| 外观事实 | 光源、观察方向、颜色、透明度、光泽、切工、可见包裹体与损伤 |
| 仪器与条件 | 仪器名称/型号、校准或检查状态、接触状态、环境与安全限制 |
| 原始读数 | 每次读数、范围、方向、重复次数、异常或无法读数的原因 |
| 解释与边界 | 支持候选、排除候选、无法排除项、未完成测试、是否送检 |

**停止条件：** 样品不可接触、存在表面/结构风险、读数不稳定或结论涉及天然/合成、处理、产地与价值时，不为了“得到一个名称”继续增加风险测试。


## 核心要点

- 记录“看到了什么”与“因此怀疑什么”两栏，避免观察与结论互相污染。
- 仪器读数应带测试条件、方向、接触状态和重复结果，不能脱离上下文比较。
- 结论强度必须低于证据强度：筛分结果不是鉴定证书，产地意见也不是分级。
- 任何破坏性测试都要先确认授权、样品价值与安全条件。
