# 合成品与仿品鉴别

## 概述

合成宝石（同化学成分，如焰熔法红宝石、水热法祖母绿、CVD 钻石）与
仿品（不同成分，如玻璃、立方氧化锆、仿祖母绿双层石）需要不同的
鉴别路径。


## 核心要点

- 合成红/蓝宝石：焰熔法曲线生长纹、气泡；水热法含铂片/不规则包裹体。
- CVD/HPHT 钻石：与天然钻石同为碳，需紫外荧光分带 + 光谱仪判断。
- 立方氧化锆 (CZ)：SG 5.65、异常色散、棱角锋利——与钻石区别明显。
- 玻璃仿品：气泡、旋涡纹、流动纹；折射率常在 1.5–1.7 区间。
