# 光学测试

## 概述

双折射（偏光镜）、多色性（二色镜）、紫外荧光（紫外灯）揭示宝石的
光学对称性与化学成分信息，是快速筛分品种与检测处理的关键。


## 核心要点

- 双折射：光在非均质宝石中分裂，值越高（如锆石 0.059）越易识别。
- 多色性：二色镜观察，堇青石三色性强、红宝石紫红/橙红。
- 紫外荧光：LW/SW 紫外灯下反应，帮助区分天然 vs 合成、产地线索。
- 光谱 (spectroscope)：吸收谱带是"指纹"，鉴定变色宝石与产地。
