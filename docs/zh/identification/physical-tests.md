# 物理性质测试

## 概述

折射率 (RI)、比重 (SG)、硬度、解理是最基础的鉴定手段——它们由
矿物化学成分与晶体结构影响；同一品种通常落在可比的特征范围，
但测量条件、方向、处理和样品状态都会影响读数。

## 鉴定步骤

**统一教学协议**

每项测试都按同一顺序阅读：目的 → 适用条件 → 操作与记录 → 结果解释 → 异常处理 → 风险/送检。参考值用于缩小候选范围，不是样品的“密码”。

| 测试 | 主要输出 | 典型限制 |
|---|---|---|
| RI | 单值/范围、方向、读数质量 | 弧面、尺寸、透明度、接触状态和量程 |
| SG | 方法、数值、重复结果 | 镶嵌、孔隙、吸液、气泡和样品重量 |
| 莫氏硬度 | 是否出现刻划现象 | 有损、相对值，不等于真伪或耐久性 |
| 解理 | 结构性风险记录 | 不通过敲击或劈开验证 |

### 1. 折射率（RI）

**目的：** 用折射率和光性信息缩小材料候选范围。

**适用条件：** 先确认折射仪可用，清洁样品和接触面，并判断样品尺寸、弧面和透明度是否适合测量。镶嵌石、过小样品或无法形成可靠接触时，应记录为不适用。

**操作与记录：** 记录单值还是范围、观察方向、接触状态、读数质量和重复稳定性。原始读数应保留，不要只记录一个经过四舍五入的“结论值”。

**结果解释：** 将读数与候选的典型范围、双折射和样品状态一起比较；RI 只能支持或排除部分候选，不能单独证明天然、合成或处理状态。

**异常处理：** 出现超出量程、边界模糊、接触不良或读数不稳定时，记录“无法可靠读数”和原因，改用适合样品的下一项非破坏性观察。

**风险/送检：** 不为了得到名称而反复施压或污染样品；涉及高价值、正式披露或读数冲突时保留原始记录并送检。

### 2. 比重（SG）

**目的：** 将质量与体积关系作为候选材料的补充证据。

**适用条件：** 先判断样品是否适合液体或静水法。镶嵌、孔隙、吸液、表面损伤、极小样品或复合结构都可能使结果失真。

**操作与记录：** 只按设备、液体和实验室安全说明操作，记录方法、样品状态、环境、重复结果、气泡/接触器具情况和必要修正。不要把未经检查的单次称重写成确定值。

**结果解释：** SG 只能与 RI、光性、显微观察和候选范围交叉解释；单个 SG 数值不能直接等同于宝石名称。

**异常处理：** 气泡、液体污染、样品吸液、接触器具干扰或重复结果差异明显时，标记结果不可靠，不继续用它排除候选。

**风险/送检：** 液体、样品表面和废液按器材说明及安全数据处理；样品不适用或价值较高时跳过液体测试并考虑送检。

### 3. 莫氏硬度

**目的：** 在明确授权和风险可接受时，记录相对刻划抗性。

**适用条件：** 莫氏硬度不是第一选择。高价值、镶嵌、裂隙明显、易损或表面处理样品默认不做刻划测试。

**操作与记录：** 若经授权实施，只记录测试位置、工具、方向和是否出现刻划现象；不能把“没有划痕”写成真品证明。

**结果解释：** 莫氏硬度是相对刻划抗性，不等于真伪、耐久性、透明度或价值；不同操作者和表面状态也会影响观察。

**异常处理：** 结果不清晰、样品表面已有损伤或工具状态不明时，记录“未获得可靠硬度结果”，不要重复施加损伤。

**风险/送检：** 只要测试风险超过教育性筛分价值，就停止；正式鉴定和披露交给专业实验室。

### 4. 解理与破裂风险

**目的：** 识别结构性破裂风险，而不是主动制造破裂证据。

**适用条件：** 根据已知矿物结构、外观裂隙和样品状态做风险记录；解理、断口、裂隙和已有损伤分开描述。

**操作与记录：** 记录可见的方向性结构线索、既有损伤和不可测试原因，不通过敲击、劈开或强行施力验证解理。

**结果解释：** 解理是结构性破裂倾向，不能默认它在成品外观上可见，也不能单独用于命名。

**异常处理：** 结构风险不明确或样品出现松动、裂隙扩展迹象时，立即停止接触性测试并记录状态。

**风险/送检：** 对钻石等存在明显破裂风险的样品，把解理作为停止信号，交给专业人员评估。


## 核心要点

- 折射率（RI）和比重（SG）应视为带条件的典型参考范围；方向、仪器、接触状态、处理和样品状态都会影响读数。
- 硬度是相对刻划抗性，不等于真伪、耐久性或价值；划痕测试可能损伤样品。
- 解理是结构性破裂倾向，不应通过敲击或劈开验证，也不应默认它在外观上可见。
- 任何读数都要与样品状态、重复结果和其他证据一起解释，不能脱离上下文比较。
