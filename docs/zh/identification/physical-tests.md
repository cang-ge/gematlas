# 物理性质测试

## 概述

折射率 (RI)、比重 (SG)、硬度、解理是最基础的鉴定手段——它们由
矿物化学成分与晶体结构决定，同一矿物种的值恒定可重复。


## 核心要点

- 折射率 (RI)：折射仪读数，钻石 2.42、刚玉 1.76、石英 1.54 等。
- 比重 (SG)：空气中与水中称重比，可区分同色不同种宝石。
- 硬度：莫氏 1–10，划痕测试是破坏性的，只在必要时用。
- 解理：沿原子面断裂的倾向，钻石八面体解理、宝石级可见。

## 示例

| 宝石 | 数值 | 备注 |
|---|---|---|
| diamond | RI 2.42, SG 3.52 | — |
| ruby | RI 1.76, SG 4.00 | — |
