| 属性 | 值 |
|---|---|

## 光学性质

| 属性 | 值 |
|---|---|
| 多色性 | none |
| 典型颜色 | 血红（阿卡）, 粉色（momo）, 白色, 天使皮 |
| 致色原因 | 铁/有机色素 |

## 处理与披露

| 处理方式 | 详情 |
|---------|------|
| 常见方法 | waxing, dyeing |
| 需披露 | 是 |
| 备注 | 深血红日本阿卡珊瑚最贵；忌酸与高温 |

| 产地 |

## 历史与传说

珊瑚自古用于宗教与王室饰品，古罗马称其可避雷。日本阿卡珊瑚在明清中国极受追捧。
