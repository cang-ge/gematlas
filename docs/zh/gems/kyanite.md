# 蓝晶石

> 硅酸盐（蓝晶石）

<!-- language switcher hint -->
English: [Kyanite](/gems/kyanite)

---

## 分类

| 属性 | 值 |
|---|---|
| 矿物族 | 硅酸盐（蓝晶石） |
| 化学式 | Al₂SiO₅ |
| 晶系 | triclinic |

## 物理性质

| 属性 | 值 |
|---|---|
| 莫氏硬度 | 5.5（硬度方向性：长度 4.5 / 横截面 7） |
| 比重 | 3.68 |
| 折射率 | 1.71-1.73 |

## 光学性质

| 属性 | 值 |
|---|---|
| 多色性 | strong |
| 典型颜色 | 湛蓝, 蓝黑, 绿 |
| 致色原因 | Fe/Ti 致蓝色 |

## 处理与披露

| 处理方式 | 详情 |
|---------|------|
| 常见方法 | heating |
| 需披露 | 否 |
| 备注 | 硬度各向异性极罕见；橙色蓝晶石（锰致色）更贵 |

## 主要产地

| 产地 |
|---|
| 巴西 |
| 尼泊尔 |
| 缅甸 |
| 美国北卡罗来纳 |

## 历史与传说

蓝晶石得名于希腊"蓝色"，其各向异性硬度（横纵差异）在宝石界独一无二。
