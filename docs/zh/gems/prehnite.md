# 葡萄石

> 硅酸盐（层状）

<!-- language switcher hint -->
English: [Prehnite](/gems/prehnite)

---

## 分类

| 属性 | 值 |
|---|---|
| 矿物族 | 硅酸盐（层状） |
| 化学式 | Ca₂Al(AlSi₃O₁₀)(OH)₂ |
| 晶系 | orthorhombic |

## 物理性质

| 属性 | 值 |
|---|---|
| 莫氏硬度 | 6.25 |
| 比重 | 2.9 |
| 折射率 | 1.611-1.672 |

## 光学性质

| 属性 | 值 |
|---|---|
| 多色性 | weak |
| 典型颜色 | 浅绿色（葡萄绿）, 黄绿色, 无色至白色 |
| 致色原因 | Fe³⁺ 致浅绿至黄绿 |

## 处理与披露

| 处理方式 | 详情 |
|---------|------|
| 常见方法 | 无 / 通常无处理 |
| 需披露 | 否 |
| 备注 | 常与葡萄状晶形关联；镶嵌以吊坠/雕刻为主 |

## 主要产地

| 产地 |
|---|
| 南非 |
| 澳大利亚 |
| 中国 |
| 美国新泽西 |

## 历史与传说

葡萄石以荷兰殖民者Hendrik von Prehn命名，是首个以人名命名的矿物。
