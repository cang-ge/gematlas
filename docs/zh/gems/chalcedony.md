# 玉髓 / 玛瑙
<img src="../../images/gems/chalcedony/chalcedony-gallery-1.jpg" alt="玉髓 / 玛瑙" style="max-width:100%;border-radius:var(--radius-md,4px);margin-bottom:1rem">





> 石英族（隐晶质）

<!-- language switcher hint -->
English: [Chalcedony / Agate](/gems/chalcedony)

---

## 分类

| 属性 | 值 |
|---|---|
| 矿物族 | 石英族（隐晶质） |
| 化学式 | SiO₂ |
| 晶系 | trigonal |

## 物理性质

| 属性 | 值 |
|---|---|
| 莫氏硬度 | 7 |
| 比重 | 2.6 |
| 折射率 | 1.530-1.543 |

## 光学性质

| 属性 | 值 |
|---|---|
| 多色性 | none |
| 典型颜色 | 多种颜色（带状玛瑙）, 蓝色（蓝玉髓）, 黑色（缟玛瑙）, 白色（白玉髓）, 红色（红玉髓/光玉髓） |
| 致色原因 | 杂质/包裹体致色；染色工艺常见 |

## 处理与披露

| 处理方式 | 详情 |
|---------|------|
| 常见方法 | dyeing, heat-treatment |
| 需披露 | 是 |
| 备注 | 玛瑙的染色技术已有数千年历史；几乎市场上的所有黑玛瑙和蓝玛瑙都是染色产物 |
