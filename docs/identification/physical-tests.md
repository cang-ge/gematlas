# Physical Tests

## Overview

Refractive index, specific gravity, hardness, and cleavage are the
most basic identification tools — influenced by chemistry and crystal
structure, so each species tends to fall within a comparable range; conditions,
orientation, treatment, and sample state can shift the reading.


## Core Principles

- Refractive index: refractometer reading; diamond 2.42, corundum 1.76, quartz 1.54.
- Specific gravity: weigh in air vs water; separates same-colour species.
- Hardness: Mohs 1–10; scratch tests are destructive — use only when needed.
- Cleavage: tendency to break along atomic planes; octahedral in diamond.

## Examples

| Gem | Value | Note |
|---|---|---|
| diamond | RI 2.42, SG 3.52 | highest RI of gems |
| ruby | RI 1.76, SG 4.00 | corundum signature |
