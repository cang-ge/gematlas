# GemAtlas 欧珀首页 Hero 设计规范

## 状态

- 状态：实现完成，等待用户体验复核。
- 日期：2026-09-07
- 范围：独立首页 Hero 与进入知识百科主页的入口体验。
- 当前项目约束：GemAtlas 当前使用 VitePress + Vue 3 + TypeScript，不迁移到 React/Tailwind/shadcn。

## 目标

把首页第一屏做成“从一束光，认识一颗宝石”的沉浸式入口：访客先看到暗场中的欧珀成品，再看到全屏光线缓慢扫过，欧珀变彩逐渐显现，最后通过顶部模块入口进入五个知识板块。

首页 Hero 负责建立视觉记忆和学习动机，不在第一屏塞入完整科普内容；欧珀的成因、变彩原理、切割与鉴定细节继续由现有知识页面承载。

## 已确认的视觉方向

### 主体素材

采用 A 方向的叙事骨架：展柜正面、欧珀成品微距、主体占据主要视觉重量。候选素材为 Wikimedia Commons 的 Rainbow Shield 欧珀吊坠照片（2807×3358，作者 Dpulitzer，CC BY-SA 4.0）。正式纳入仓库前必须下载本地副本、核对文件页信息，并在 `docs/image-credits.md` 中记录作者、来源、许可和本地处理方式。

素材处理原则：

- 优先保留欧珀、金属镶嵌和真实反光，不使用生成式宝石替换真实主体。
- 采用微距裁切和轻微镜头推进，让成品进入画面主体，而不是固定在底部作为装饰。
- 裁切必须保留标题安全区和欧珀轮廓；桌面、展签等背景信息不作为 Hero 的主要叙事。
- 如果素材无法同时满足清晰度、构图和开源许可，保留素材候选但不纳入正式首页，等待更合适的授权照片或视频。

### 版式

- 全屏深色展柜舞台，首页根节点至少占满 `100svh`，兼容移动端地址栏变化。
- 标题始终位于视觉中心：`从一束光，认识` / `一颗宝石。`。
- 成品以微距比例从暗场中显现，初始位置接近中心视觉轴；不使用“底部孤立悬浮宝石”构图。
- 标题与成品之间保留暗部安全区，用构图和低强度暗部渐变保障可读性，不使用厚重遮罩压平素材。
- 顶部为一组玻璃胶囊模块跳转键：`01 分类`、`02 鉴定`、`03 切割`、`04 分级`、`05 画廊`。当前模块高亮，键面具有清晰的 hover、focus-visible 和 active 状态。
- 移动端允许模块胶囊横向滚动，但每个入口触控区域不小于 44×44px；不依赖 hover 才能发现入口。

### 文案

- 主标题：`从一束光，认识一颗宝石。`
- 辅助文案：`光线掠过欧珀的微小结构，沉睡的色彩开始显现。进入 GemAtlas，从看见开始学习。`
- Hero 行动入口：进入知识百科主页；按钮文案可使用 `开始探索`。
- 事实型说明不在 Hero 中夸大：变彩动画是对光线揭示过程的视觉化表达，不宣称照片中的欧珀在现实中自行变色。

## 动效时间线

动效目的为“解释”和“避免突兀切换”，不是持续刺激。媒体本身承担主要运动，UI 只做必要的状态反馈。

总循环约 20 秒：

| 时间 | 状态 | 视觉行为 |
| --- | --- | --- |
| 0–3 秒 | 暗场建立 | 成品保持低亮度，仅保留轮廓和极弱环境反光；标题保持可读。 |
| 3–15 秒 | 光线揭示 | 光线以匀速、低对比度从全屏暗部缓慢扫过；经过欧珀区域时，变彩从局部逐步扩展。使用 `linear` 控制扫描，不在中段突然加速。 |
| 15–20 秒 | 色彩停留 | 保留最完整的变彩和金属反光约 5 秒，让用户真正看清，再回到循环起点。 |

实现选择：首版优先使用 CSS animation + `transform` / `opacity` / `clip-path`，配合本地真实照片实现镜头推进、光线扫掠和色彩显现；不为这一段引入动画库。若之后取得合适的真实欧珀转动视频，视频仅替换媒体层，保留同一套标题、导航和可访问性接口。

动效约束：

- 光束覆盖全屏，不固定为左侧单根竖线。
- 光束速度恒定；亮度和颜色的变化可以缓慢淡入，但不能使用中段加速制造闪烁。
- 镜头推进幅度很小，只用于空间连续性，不让主体离开标题安全区。
- `prefers-reduced-motion: reduce` 下停留在清晰的静态最终画面，保留颜色和对比度，不执行推进、扫掠和循环。
- 用户主动点击“重播光线揭示”时，即使系统启用减弱动效，也允许单次播放完整揭示序列。
- 所有 hover 动效只在支持精确指针的设备启用；焦点状态必须立即可见。

## 页面结构与导航

新增独立首页作为站点根入口：

1. 根首页展示欧珀 Hero。
2. Hero 的主行动入口进入独立知识百科入口 `/zh/compendium/`；英文入口进入 `/compendium/`，避免与沉浸式 Hero 首页形成回跳。
3. 顶部五个模块键复用现有模块路由，不复制模块内容，也不在 Hero 内嵌第二套导航数据。
4. 原有知识入口内容保留在独立百科页，避免用户从入口动效直接失去已有内容。

组件职责建议：

- `GemAtlasLanding.vue`：页面结构、Hero 文案、入口跳转和 reduced-motion 状态。
- `OpalRevealMedia.vue`：素材加载、poster/fallback、光束与变彩揭示层、时间线。
- `ModuleJumpNav.vue`：五个模块入口、当前状态、键盘焦点和移动端横向滚动。

组件之间只通过明确的 props / links 传递素材和路由，不新增全局状态管理。

## 加载、失败与性能

- 正式素材必须本地化，避免首页依赖第三方 CDN 运行。
- 为首屏图片预留固定容器比例，避免图片加载造成布局位移。
- 图片加载失败时显示深色展柜背景、标题和可用的“进入知识百科”按钮；不得出现破碎图片图标作为唯一内容。
- 如果未来使用视频，必须提供本地 poster、`muted`、`playsInline`、循环控制，并在移动端和 reduced-motion 模式下允许只显示 poster。
- 首屏只加载一套主媒体，不同时预加载多个候选素材。
- 动效只改变合成友好的属性；避免动画驱动布局尺寸、页面滚动或高频 JS 定时器。

## 无障碍与交互验收

- 标题、辅助文案、导航和主入口在键盘顺序中可访问。
- 五个模块入口为真实链接，拥有清晰的可见焦点环和当前状态，不仅依赖颜色区分。
- 图片 alt 说明真实主体；装饰性的光束和色彩层标记为隐藏。
- 文字与背景满足至少 4.5:1 的普通文本对比度；中央标题在最亮变彩状态仍可读。
- 触控目标至少 44×44px，移动端无横向页面溢出。
- `prefers-reduced-motion`、图片失败和慢速网络都能得到可用的静态体验。

## 验收标准

### 视觉

- 第一眼主体是欧珀成品，不是背景图片或装饰光束。
- 标题始终处于屏幕中央且不被主体高亮区域破坏可读性。
- 光线在约 15 秒内匀速扫过全屏，变彩缓慢显现并停留约 5 秒。
- 顶部五个模块入口完整显示，编号连续为 01–05，且具有明确 active/focus 状态。
- 桌面端、窄屏移动端均无裁切到无法识别主体或无法点击入口的情况。

### 工程

- `pnpm validate:data` 通过。
- `pnpm generate:pages` 通过且不产生非预期页面差异。
- `pnpm test` 通过。
- `pnpm build` 通过。
- 生产页面不依赖未经记录许可的外部图片或视频。
- 至少完成一次真实浏览器检查：首屏加载、五个模块跳转、主入口跳转、键盘焦点、图片失败 fallback 和 reduced-motion。
