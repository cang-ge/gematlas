# Round Brilliant Cut

## Overview

The classic diamond cut — standard 57–58 facets, formalised by
Marcel Tolkowsky's 1919 proportion theory. Table, crown, girdle,
and pavilion proportions maximise internal reflection and fire.


## Core Principles

- Standard 57 facets: 1 table + 33 crown + 24 pavilion (+ optional culet = 58).
- Table diameter ~53–58%; crown angle 34–35°; pavilion angle 40.75–41.2°.
- Girdle must balance durability against weight retention.
- Brilliance depends on precise proportions; errors create "windows" of light leakage.
