# Clarity Inclusion Types

## Overview

The type, position, quantity, and visibility of inclusions and blemishes
determine the clarity grade. The same feature matters differently in
different gems—a "jardin" is normal in emerald but critical in diamond.


## Core Principles

- Feather: fracture; worst for durability.
- Cloud: hazy cluster; degrades transparency if dense.
- Crystal / mineral: trapped inclusions (rutile, zircon, calcite).
- Needle: rutile silk; gives sapphire its velvety look.
- Blemish: surface chip / scratch / pit.
- Location dominates type—a feather under the table is much worse than one in the pavilion.

## Examples

| Gem | Grade | Note |
|---|---|---|
| emerald | jardin (3-phase) | accepted aesthetic feature |
| ruby | silk (rutile needles) | source of asterism |
