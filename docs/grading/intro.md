# Grading

Grading turns the stone's weight, appearance, and authenticity into
standardized numbers that traders and labs can compare across regions.
This module covers the GIA 4C diamond framework (Carat / Color / Clarity /
Cut), the hue-tone-saturation model for coloured gems, and the disclosure
norms for clarity types, treatments, and origin reports.
