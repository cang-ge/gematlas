同色宝石判别 ​

概述 ​

同一种颜色可能对应多种宝石——红色可能是红宝石、尖晶石、石榴石或玻璃。 结合 RI / SG / 多色性 / 包裹体，可以逐步缩小候选范围，但重叠与无法排除是正常结果。 当前提供红、蓝、绿三个最小教育性分流案例；它们用于训练“候选—证据—下一步”，不是覆盖所有材料的完整决策树。

IDENTIFICATION BOUNDARY

边界与安全

同色案例用于练习“候选—证据—下一步”的思路，不是按颜色和单个 RI 读数自动命名。红、蓝、绿分支都是最小教育性案例，不能覆盖所有材料、处理和仪器条件。无法排除或结果冲突时应停止过度推断并送检。

鉴定步骤 ​

统一阅读协议

每个颜色案例都按同一顺序处理：先固定观察条件 → 形成候选集 → 选择适用的低风险证据 → 记录支持/冲突/无法排除 → 决定是否升级。颜色只负责提出问题，不能直接给出名称。

一、蓝色候选分流 ​

1. 固定颜色与观察条件

在记录“蓝色”前注明光源、背景、是否镶嵌、透明度和切磨。坦桑石的蓝紫外观会随晶体方向、切磨取向和光源变化；堇青石也可能因方向显示蓝紫、灰蓝或近无色/黄色线索。因此，先记录“在什么条件下看到什么颜色”，不要只记录一个色名。

2. 用 RI 形成候选集

典型参考候选方向下一步
1.762–1.770刚玉族蓝宝石候选记录双折射、多色性、样品状态和处理线索
1.691–1.700坦桑石候选结合方向性多色性、切磨和热处理背景复核
约 1.54–1.55堇青石候选用二色镜记录方向颜色，不与蓝宝石名称绑定
读数不稳定/无法接触暂不分流记录“不适用/不可靠”，不要用外观补结论

上表是典型参考范围，不是硬阈值。样品状态、接触质量、方向和仪器条件可能使读数缺失或偏离；同一颜色下仍可能存在重叠候选。

3. 用多色性提出下一步问题

观察能支持什么不能证明什么
颜色随方向明显变化支持具有方向性光学反应的候选不能单独证明是坦桑石或堇青石
颜色变化弱或未观察到当前条件下的观察记录不能直接排除蓝宝石、坦桑石或堇青石
光源改变后颜色变化明显提醒记录光源与颜色条件不能直接推出处理或产地

4. 蓝色分支的升级条件

出现 RI 与多色性冲突、样品镶嵌/弧面导致方向不可控、需要判断热处理或需要正式产地/天然披露时，停止继续凭颜色推断，保留原始观察并送专业实验室。

二、绿色候选分流 ​

1. 先区分颜色观察和材料判断

绿色可能来自祖母绿、沙弗莱石、橄榄石、绿色碧玺、翡翠或仿品。色调、透明度和“油润/玻璃感”只能用来建立候选集，不能作为排除依据。

2. 用 RI/SG 形成候选集

典型参考候选方向下一步
RI 1.577–1.583；SG 约 2.72祖母绿候选结合包裹体、处理线索和生长来源问题
RI 1.739–1.744；SG 约 3.61沙弗莱石候选与其他绿色石榴石和颜色重叠保持区分
RI 约 1.65–1.69；双折射明显橄榄石候选结合 SG、双折射、颜色和包裹体复核
读数不稳定/样品不可接触暂不分流标记限制，不能用绿色外观填补证据

这些数值是典型参考，不是自动命名规则。绿色石榴石之间可能出现颜色重叠，橄榄石的 RI/SG 也可能随颜色与包裹体变化；任何偏离都要保留条件，而不是强行选择最接近的名称。

3. 把处理与生长来源分开

祖母绿的“材料身份”与“是否注油/充填”是两个问题；绿色石榴石或橄榄石的“颜色相似”也不能推出同一矿物。处理、天然/合成、产地和价值必须分别记录，不能用一个 RI 或一个外观词替代。

4. 绿色分支的升级条件

若需要确认注油/充填、天然与合成、翡翠与其他绿色材料的身份、复合结构或正式交易披露，应停止教育性分流并送检。若 RI、SG、光学反应和显微线索互相冲突，也应把冲突作为结果记录。

三、统一结果记录模板 ​

字段示例
任务边界学习筛分 / 购买前复核 / 正式披露
样品限制镶嵌、弧面、尺寸、裂隙、可接触面
候选集蓝宝石、坦桑石；或祖母绿、沙弗莱石、橄榄石
证据状态支持候选 / 与候选一致 / 无法排除 / 不可靠
下一步补充适用证据 / 保留冲突 / 送专业实验室

案例边界

红、蓝、绿三条路径都只是最小教育性案例。镶嵌、弧面、表面裂隙、透明度低、无法接触或高价值样品不应强行套用；任何“支持候选”的结果都必须保留测试条件，结果冲突时优先记录冲突，而不是选择最符合直觉的名称。

核心要点 ​

  • 红色案例：红宝石的 RI 与荧光结果只能共同支持候选；尖晶石、石榴石和玻璃的范围可能与其他材料重叠。
  • 蓝色案例：蓝宝石、坦桑石和堇青石的 RI 与多色性可用于提出下一步问题，但仍不是完整鉴定决策树。
  • 绿色案例：祖母绿、沙弗莱石和橄榄石的物性与光学线索可用于候选分流，但必须保留条件和重叠项。
  • 荧光只能作为筛分线索：天然红宝石常见 LW 红色反应，但强弱受产地、处理与样品影响；合成品也可能出现相近反应。
  • 任何单一观察都不能替代实验室鉴定；紫外灯、划痕和液体测试须按器材安全规范操作。

示例 ​

宝石数值备注
红宝石RI 1.76 + 红色荧光支持刚玉/红宝石候选，仍需交叉复核
蓝宝石RI 约 1.76；记录方向性多色性与坦桑石、堇青石分流时需保留光源和方向
坦桑石RI 1.691–1.700；多色性典型参考，切磨和光源会影响外观
堇青石RI 约 1.54–1.55；强多色性需按方向记录颜色变化，不能单独命名

沙弗莱石榴石RI 1.739–1.744；SG 约 3.61绿色重叠候选，不能仅凭颜色命名
